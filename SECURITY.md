# Security policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Include the steps to reproduce, the affected Android version and device, and the impact.

You can expect an acknowledgement within 7 days. Once a fix is available, the report will be
credited in the release notes unless you ask otherwise.

## Scope

Lumen's lock-screen cover sits above Android's secure lock screen and never handles unlocking.
Reports showing that the cover can bypass or weaken Android's own authentication are especially welcome.
